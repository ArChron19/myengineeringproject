## Mission and approach
Our mission is to make math less intimidating by letting people solve and model equations with a few simple conventions instead of complex spreadsheet formulas. We focus on fast, practical answers: most engineers work to three significant digits, and on multiple-choice exams knowing a value to one or two significant digits is usually enough to pick the right answer.

## selectNsolve Basic
selectNsolve Basic is a free Google Sheets add-on that solves single-variable equations written as plain text in your cells, with no programming. You type constants, a variable with search bounds, and an equation; select the cells; and run the solver. It supports standard and Unicode math operators, Unicode variable names, user-defined search bounds and adjustable precision. Basic is free forever and needs no credit card.

## Developer API
The selectNsolve Developer API is a live MCP server at https://myengineeringproject.com/api/mcp that lets AI agents create and fill Google Sheets with selectNsolve math text. No API key is needed. Tools: sheets_create, sheets_read_range, sheets_write_range, sheets_format_selectnsolve and sheets_apply_template. The API does not solve equations itself; the selectNsolve Basic add-on does the solving in Google Sheets. Claude Desktop needs version 0.10.0 or later for remote MCP.
